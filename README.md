# Willow Blog

A full-stack blog app built with React (frontend) and Node/Express + MongoDB (backend). Includes auth, posts, likes, saves, comments, and notifications.

## Run locally

**Backend**
```bash
cd backend
npm install
npm run dev
```

**Frontend**
```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:5173`. Make sure `backend/.env` is set up with `MONGO_URI`, `JWT_SECRET`, and `CLIENT_URL`.
